# DL/T 645-2007 电表通信参数探测工具

自动遍历不同串口参数（波特率、数据位、校验位、停止位），探测 DL/T 645-2007 协议智能电表的通信参数。

## 功能特性

- **自动探测**：遍历多种波特率和通信参数组合
- **完整记录**：记录所有尝试的结果（成功/失败）
- **CSV 导出**：一键导出扫描结果到 CSV 文件
- **可配置超时**：自定义等待电表应答的时间（毫秒），超时自动切换下一组参数
- **手动串口控制**：先打开串口，再手动发送报文测试
- **帧解析**：自动解析回复帧的地址、控制码、数据标识、数据值
- **FE 前缀过滤**：自动过滤电表回传的唤醒字节 `FE`，正确识别帧格式
- **GUI 界面**：提供可视化的操作界面（`meter_scan_gui.py`）

## 支持波特率

1200 / 2400 / 4800 / 7200 / 9600 / 19200 / 38400 / 57600 / 115200 bps

## 使用方法

### 手动测试模式

1. 选择串口，设置通信参数（波特率/数据位/校验/停止位）
2. 点击 **🔌 打开串口**
3. 在输入框填入报文（十六进制，空格分隔）
4. 勾选/取消勾选「先发唤醒 FE」
5. 点击 **📤 发送**
6. 在日志区查看解析结果

### 自动探测模式

1. 勾选要测试的波特率
2. 设置等待超时（默认 1500ms）
3. 点击 **▶ 开始探测**
4. 完成后点击 **📄 导出 CSV**

## 探测原理

1. 对每个参数组合，发送唤醒字节 `FE FE FE FE`
2. 发送 DL/T 645-2007 读通信地址报文：`68 AA..AA 68 13 00 CS 16`
3. 等待电表应答，**在设定的超时时间内未收到则自动切换下一组参数**
4. **自动过滤 `FE` 前缀**，正确识别从 `68` 开始的帧
5. 验证帧格式和校验码，记录成功匹配的参数组合

## 关于 `FE` 前缀过滤

某些电表或采集器会把收到的唤醒字节 `FE` 回传。例如：

```
RX: FE FE FE FE 68 12 89 67 45 23 01 68 91 0A ... 48 16
    └─ 唤醒回传 ─┘ └─ 实际应答帧 ─┘
```

工具会自动跳过开头的 `FE` 字节，找到第一个 `68` 帧头进行解析。

## 等待超时建议值

| 场景 | 建议超时 | 说明 |
|------|---------|------|
| 快速扫描 | 300~500 ms | 响应快的现代电表 |
| 默认/通用 | 1500 ms | 兼顾速度和兼容性 |
| 老旧电表 | 3000~5000 ms | 老款设备响应慢 |
| 远距离/总线 | 5000+ ms | RS-485 末端设备 |
